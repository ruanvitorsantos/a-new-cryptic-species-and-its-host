# Preliminary analyses

Earlier approaches kept for transparency. They are **not** the analyses reported in the manuscript.

* `ppi_orthology_string_api/` - first attempt at a protein-protein interaction network for the *Agave sisalana* DEGs, transferring
  STRING interactions from five reference species (*Arabidopsis thaliana*, *Musa acuminata*, *Oryza sativa* Japonica, *Sorghum bicolor*,
  *Zea mays*) through OrthoFinder orthogroups. The network reported in the manuscript (Methods 5.2.6) uses pineapple
  (*Ananas comosus*) as the reference species and Louvain community detection instead.

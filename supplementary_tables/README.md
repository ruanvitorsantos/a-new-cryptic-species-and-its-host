# Supplementary tables

Tables that are too large for the manuscript. Numbering follows the Supplementary Material of the manuscript.

| File | Content |
| --- | --- |
| `S3_Mash_ANI_matrix_k21_120genomes.tsv` | Mash-based ANI (%) matrix, k = 21, sketch size 10,000, among 120 genomes (Section 4.2.4) |
| `S4_pyANI_ANIm_matrix_120genomes.tsv` | pyANI ANIm (%) matrix among the same 120 genomes (Section 4.2.4) |

Rows and columns of both matrices are the genome labels (species and strain) of the 120 genomes (66 *A. niger* clade, 22 *A. welwitschiae* clade,
31 *A. tubingensis* clade and strain CCMB 674).

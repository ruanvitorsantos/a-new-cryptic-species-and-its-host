# Protein-protein interaction network (Methods 5.2.6)

Python scripts used for the DEG-based interaction network of *Agave sisalana*: selection of transcripts with open reading frames,
recovery of DEGs without ORF by translated alignment, choice of the reference species, STRING edges (experiments, co-expression,
gene neighborhood, co-occurrence and gene fusion channels; score >= 0.7), Louvain modules (NetworkX, seed 42), module enrichment
and figures.

The scripts were run from the transcriptome work directory (`[diretório_transcriptoma]`) and read the files written by one another;
they are listed here exactly as they were run, and no execution order was recorded. Input files that are not generated by these
scripts (STRING downloads, DIAMOND hit tables, TransDecoder proteins) are expected in `[diretório_transcriptoma]` and its sub-folders
(`protein/`, `string_db/`, `string_db5/`, `ref5/`, `ref7/`).

The translated alignment (BLASTX) of the DEGs without a predicted ORF against the reference proteomes was run directly in the terminal
and no script was saved for it; `diamond5.sh` only covers the BLASTP comparison of the canonical proteins against the five reference
proteomes. The resulting hit tables are read by the scripts in this folder.
